# Project Z · Kaldran City

Playable Windows development build of the first square kilometre. Start **New Game** to wake up in Hillview Steps on Day 21. **First Light** takes you from the apartment and corner shop through the city to the pumping station and police annex, then back to defend the safehouse. The world stays open after the mission.

## Play or edit

- **Windows:** Extract the Windows ZIP to a local folder. Double-click `ProjectZ.exe` with `ProjectZ.pck` in the same folder.
- **Godot:** Import this folder's `project.godot` in Godot 4.7.2 and run the project. `kaldran_city.tscn` is the default scene.
- Press **E** near a case, door or fixture while facing it. The first supply case is in the apartment lobby. Equip the crowbar from the field pack.
- The red Carmine GT is parked outside Hillview Steps. Face the driver’s door and press **E** to get in. Drive with **WASD**, brake with **Space**, and toggle the headlights with **F**. Stop before pressing **E** to exit.

| Key | Action |
| --- | --- |
| W A S D · mouse | Move and look |
| Shift · Ctrl · Space | Sprint, crouch, jump |
| Mouse wheel | Camera distance |
| E · F | Interact and flashlight |
| Left mouse · right mouse · R | Attack, aim, reload |
| Tab · M · J | Pack and crafting, map, journal |
| Esc · F5 · F3 | Pause, save, diagnostics |

Keyboard controls can be remapped in Settings. The game saves to the current Windows user's Godot application data. New Game creates a fresh run.
