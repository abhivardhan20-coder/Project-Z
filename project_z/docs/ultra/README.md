# Ultra Graphics for Kaldran City

Open **Material Lab** from the title screen to compare material samples and P06 Hillview. Select Clear, Overcast, or Rain and move the slider to change the time of day. In the playable city, use the weather and quality menus in Settings. The lab does not write a game checkpoint.

Project Z uses Godot 4.7.2 and defaults to Forward+ on desktop. Run with `--rendering-method gl_compatibility` to explicitly select the fallback. The demo package includes the city and material lab in one executable.
