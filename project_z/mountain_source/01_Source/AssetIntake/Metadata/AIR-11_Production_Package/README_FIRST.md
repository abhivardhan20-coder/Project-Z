# AIR-11 asset package

**LOD0: 348,304 real triangles**, 6 x 12 x 3.6 m tent module.

Open `Previews/AIR-11_hero.png` and `Previews/AIR-11_interior.png`, then import `AIR-11_LOD0.glb` into Blender/Godot 4. To create `.blend`, use an installed Blender with `blender -b --python AIR-11_blender_import.py`. The current environment could not run Blender. For game integration, read `Godot4/README_GODOT.md` and test the demo `Godot4/AIR-11_Tent.tscn` inside your project.

For actual exported triangle counts and test exclusions, see `AIR-11_validation.md`.
