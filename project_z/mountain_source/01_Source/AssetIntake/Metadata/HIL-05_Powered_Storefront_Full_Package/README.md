# HIL-05 Powered Neighborhood Storefront

A **real 3D, game-oriented storefront model** created from the attached HIL-05 multi-view reference, with an accessible retail area and stockroom. Not an image-only mockup.

**Start here:** `HIL-05_LOD0.glb`. For Godot, use `Godot4/README.md`. For the production triangle counts, UV/material/animation/import verification, scale and untested limitations, read `HIL-05_validation.md` and `HIL-05_manifest.json`.

**Package includes:** LOD0/LOD1/LOD2 glTF 2.0 binary models; flat-color HLOD; material texture sources; original multi-view reference image; eight geometry-based views; reproducible geometric construction source; Blender-import-and-save source script; Godot 4 door/collider script and QA manifest.

The three main GLBs contain embedded PBR material maps and no missing external texture paths. High-detail reference colors/finishes are an approximation rather than licensed scanned materials.

**Not included:** native `.blend` or verified Godot engine screenshot because neither Blender nor Godot was available in the authoring runtime. These omissions are explicitly identified rather than represented as completed tests.
